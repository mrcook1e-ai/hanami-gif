# Hanami GIF Generator

Инструменты для генерации качественных GIF-анимаций (Hanami Project).

## 1. Установка

1. Установите [Node.js](https://nodejs.org/) (версия 18+).
2. Скачайте проект.
3. Откройте консоль в папке проекта и выполните:

```bash
npm install
```

---

## 2. Использование

В проекте есть два основных скрипта: **генератор числа** и **конвертер видео в GIF**.

### A. Генерация числа (сборка из слоев)

Скрипт берет PNG-секвенции из папки `assets/` (bg, pg, fg), накладывает на них число и собирает GIF.

**Команда:** `npm start <ЧИСЛО> -- [ПАРАМЕТРЫ]`

**Примеры:**

```bash
# 1. Максимальное качество (оригинал ~15-20 MB)
npm start 5

# 2. Оптимальное сжатие (качество 80%)
npm start 5 -- --quality 80

# 3. Быстрый рендер (для тестов)
npm start 99 -- --fast

# 4. Уменьшить размер картинки (например, ширина 480px)
npm start 10 -- --width 480
```

---

### B. Конвертер видео в GIF (Аватарки)

Скрипт берет видеофайл (например, `Avatar.mov`), обрезает его в квадрат 1024x1024 и делает GIF.

**Команда:** `npm run avatar -- <ИМЯ_ФАЙЛА> [ПАРАМЕТРЫ]`

**Примеры:**

```bash
# 1. Конвертировать Avatar.mov (по умолчанию)
npm run avatar

# 2. Конвертировать другой файл с сжатием
npm run avatar -- my_video.mp4 --quality 80

# 3. Изменить размер (например, 512x512)
npm run avatar -- Avatar.mov --width 512 --height 512
```

---

## 3. Доступные параметры (Gifski)

Эти флаги можно использовать в обоих скриптах (после `--`):

| Флаг | Описание | По умолчанию |
| :--- | :--- | :--- |
| `--quality <1-100>` | Качество GIF. Меньше = легче файл. | `100` (Макс) |
| `--fps <число>` | Частота кадров. | `25` |
| `--fast` | Ускорить кодирование в 2 раза (чуть хуже сжатие). | Откл. |
| `--width <px>` | Ширина картинки. | `960` (Gen) / `1024` (Avatar) |
| `--height <px>` | Высота картинки. | `540` (Gen) / `1024` (Avatar) |
| `--repeat <0/-1>` | `0` = вечный повтор, `-1` = один раз. | `0` |

---

## 4. Структура проекта

*   `generate.ts` — Скрипт сборки GIF из слоев.
*   `avatar.ts` — Скрипт конвертации видео.
*   `assets/` — Папка с исходными PNG-секвенциями (`bg`, `pg`, `fg`).
*   `.tmp/` — Временные файлы (удаляются автоматически).
*   `output.gif` — Результат работы генератора.

## 5. Решение проблем

**Ошибка:** `npm error ...`
> Используйте разделитель `--` перед флагами: `npm start 5 -- --quality 80`

**Ошибка:** `Error: File not found`
> Проверьте, что видеофайл лежит в корне проекта и его имя написано правильно.

**Ошибка:** `Gifski Error: Found argument '--hight'`
> Проверьте написание флагов. Правильно: `--height`.
